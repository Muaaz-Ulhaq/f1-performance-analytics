# F1 Performance Analytics

Post-race and qualifying analysis of Formula 1 sessions using the FastF1 library:
telemetry, corner-by-corner time loss, race pace and tyre degradation.

## Setup

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

## Scripts

- `scripts/01_explore_session.py` - load a session, inspect laps and telemetry
